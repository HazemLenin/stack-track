# Database schema (ERD)

Source of truth for the Stack Track data model. Feature tickets, EF Core configuration and migrations follow this document. Database: PostgreSQL.

## Conventions

- Primary keys are GUIDs (`uuid`), column `Id`, generated by the application.
- Every table has `CreatedAt` and `UpdatedAt` (`timestamptz`, UTC). `UpdatedAt` is set on every write.
- Join tables (`BoardMember`, `CardAssignee`, `CardLabel`) also have their own GUID `Id`, so the two rules above hold for every table. The pair of foreign keys is made unique instead (see [Unique constraints](#unique-constraints)).
- Foreign key columns are named `<Entity>Id` (`OwnerId`, `AuthorId`, `ReplacedByTokenId` where the role matters).

```mermaid
        uuid Id PK
        string Email UK
        string DisplayName
        string PasswordHash
        string Role "Admin or Member"
        boolean IsActive
        datetime CreatedAt
        datetime UpdatedAt
    }
    Board {
        uuid Id PK
        uuid OwnerId FK
        string Name
        boolean IsArchived
        datetime CreatedAt
        datetime UpdatedAt
    }
    BoardMember {
        uuid Id PK
        uuid BoardId FK
        uuid UserId FK
        datetime JoinedAt
        datetime CreatedAt
        datetime UpdatedAt
    }
    List {
        uuid Id PK
        uuid BoardId FK
        string Name
        double Position
        datetime CreatedAt
        datetime UpdatedAt
    }
    Card {
        uuid Id PK
        uuid ListId FK
        string Title
        string Description
        double Position
        datetime DueDate "nullable"
        datetime CreatedAt
        datetime UpdatedAt
    }
    CardAssignee {
        uuid Id PK
        uuid CardId FK
        uuid UserId FK
        datetime CreatedAt
        datetime UpdatedAt
    }
    Label {
        uuid Id PK
        uuid BoardId FK
        string Name
        string Color
        datetime CreatedAt
        datetime UpdatedAt
    }
    CardLabel {
        uuid Id PK
        uuid CardId FK
        uuid LabelId FK
        datetime CreatedAt
        datetime UpdatedAt
    }
    Comment {
        uuid Id PK
        uuid CardId FK
        uuid AuthorId FK
        string Body
        datetime CreatedAt
        datetime UpdatedAt
    }
    RefreshToken {
        uuid Id PK
        uuid UserId FK
        string TokenHash UK
        datetime ExpiresAt
        boolean IsRevoked
        uuid ReplacedByTokenId FK "nullable"
        datetime CreatedAt
        datetime UpdatedAt
    }
```
